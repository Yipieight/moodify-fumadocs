### Patrones de Rutas Especiales

- **`(auth)`**: Grupo de rutas para autenticación sin afectar la URL
- **`[id]`**: Parámetros dinámicos en rutas
- **`[[...slug]]`**: Parámetros catch-all para rutas anidadas
- **`not-found.tsx`**: Páginas 404 personalizadas
- **`error.tsx`**: Manejo de errores por segmento
- **`loading.tsx`**: Estados de carga optimistas

### Principios de Diseño de Componentes

1. **Atomic Design**: Componentes construidos desde átomos hasta organismos
2. **Reutilización Máxima**: Cada componente debe ser usable en múltiples contextos
3. **Tipado Estricto**: Todos los componentes deben tener interfaces TypeScript definidas
4. **Accesibilidad**: Cumplimiento de WCAG 2.1 AA
5. **Responsive Design**: Funcionamiento en todos los tamaños de pantalla

### Servicios Clave

1. **`auth.ts`**: Configuración de proveedores de autenticación y callbacks
2. **`prisma.ts`**: Cliente tipado de Prisma con configuración de conexión
3. **`spotify.ts`**: Wrapper tipado para la API de Spotify con manejo de tokens
4. **`validation.ts`**: Esquemas Zod para validación de datos en toda la aplicación
5. **`chartConfig.ts`**: Configuración común para Chart.js con temas consistentes

## Convenciones de Nomenclatura

### Archivos y Componentes
- **Componentes React**: PascalCase (`UserProfile.tsx`)
- **Hooks personalizados**: `use` + PascalCase (`useAuth.ts`)
- **Utilidades**: camelCase (`formatDate.ts`)
- **Constantes**: UPPER_SNAKE_CASE (`API_ENDPOINTS.ts`)

### Estilos y Clases CSS
- **Clases Tailwind**: Utilizar utilidades de Tailwind CSS
- **Clases personalizadas**: Prefijo con `moodify-` (`moodify-gradient-primary`)
- **Variants**: Utilizar sistema de variants de Tailwind

### Importaciones
- **Alias de ruta**: `@/components/Button` en lugar de `../../components/Button`
- **Importaciones nombradas**: Preferir importaciones específicas
- **Orden de importaciones**: Librerías externas, luego internas, luego locales

Esta estructura organizativa permite un desarrollo escalable, mantenible y colaborativo, siguiendo las mejores prácticas de la industria para aplicaciones modernas de React/Next.js.
