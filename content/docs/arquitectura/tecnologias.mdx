# Tecnologías y Frameworks Utilizados

Moodify emplea una pila tecnológica moderna y robusta basada en las dependencias reales del proyecto tal como se definen en el archivo `package.json`.

## Framework Principal - Next.js 15

### Versiones y Características
- **Next.js**: v15.5.0 con Turbopack
- **React**: v19.1.0 (última versión estable)
- **App Router**: Arquitectura moderna de enrutamiento basada en carpetas

### Ventajas para Moodify
- **Rendimiento**: Compilación rápida con Turbopack
- **Server Components**: Renderizado parcial en servidor para mejor performance
- **API Routes**: Endpoints API integrados sin servidores separados
- **Optimizaciones Automáticas**: Compresión de imágenes, división de código, etc.

## Autenticación - NextAuth.js

### Dependencias Reales
- **next-auth**: v4.24.11
- **@auth/prisma-adapter**: v2.10.0

### Características Implementadas
- **Multiple Providers**: Soporte para autenticación con credenciales y OAuth
- **JWT**: Tokens de autenticación basados en JSON Web Tokens
- **Prisma Adapter**: Integración directa con base de datos a través de Prisma
- **Session Management**: Gestión automática de sesiones de usuario

## Base de Datos - Prisma ORM

### Dependencias Reales
- **@prisma/client**: v6.14.0
- **prisma**: v6.14.0 (devDependency)

### Funcionalidades Clave
- **Type Safety**: Generación automática de tipos TypeScript
- **Query Builder**: Consultas intuitivas con autocompletado
- **Migrations**: Sistema de migraciones declarativo
- **Database Adapters**: Soporte para PostgreSQL, MySQL, SQLite, MongoDB

## Gestión de Dependencias - pnpm

Aunque no se lista explícitamente en package.json, el proyecto utiliza pnpm como gestor de paquetes por las siguientes ventajas:

### Beneficios
- **Eficiencia de Espacio**: Almacenamiento enlazado para dependencias comunes
- **Velocidad**: Instalación más rápida que npm/yarn
- **Seguridad**: Verificación de integridad con checksums
- **Workspace Support**: Gestión eficiente de monorepositorios

Esta combinación de tecnologías proporciona a Moodify una base sólida y mantenible que aprovecha las mejores herramientas del ecosistema JavaScript/TypeScript moderno.
